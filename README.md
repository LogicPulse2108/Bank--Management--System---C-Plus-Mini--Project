# 🏦 Bank Management System

> 📌 A simple C++ console application for managing basic bank account operations.

## 🎯 About the Project

The **Bank Management System** is a console-based C++ application developed to perform basic banking operations. It allows users to create an account, deposit money, withdraw money, and display account information.

This project demonstrates my understanding of **C++, classes, objects, functions, strings, and basic banking operations**.

## ✨ Features

* 🏦 Create Bank Account
* 💰 Deposit Money
* 💸 Withdraw Money
* 👀 Display Account Details
* 📊 Check Account Balance
* 🚪 Exit the Application

## ▶️ How to Run

1. 📥 Clone or download this repository.
2. 📂 Open the project in VS Code.
3. ⚙️ Compile the C++ source file using a C++ compiler.
4. ▶️ Run the program.
5. 🖥️ Select the required banking operation.
